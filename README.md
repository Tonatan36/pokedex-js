# ⚡ Pokédex JavaScript (API Pro)



Aplicação web desenvolvida como parte dos desafios práticos de desenvolvimento web e consumo de APIs REST, integrada ao meu portfólio de estudos e transição para a área de tecnologia.



## 🚀 Tecnologias Utilizadas

* **HTML5 & CSS3** (Estruturação e estilização customizada com Flexbox/Grid)

* **JavaScript (ES6+)** (Lógica de manipulação do DOM e programação assíncrona)

* **Fetch API** (Consumo da PokeAPI em tempo real)

* **Git & GitHub** (Versionamento de código e hospedagem via GitHub Pages)



## 📌 Funcionalidades

* Listagem dinâmica de Pokémons consumindo dados oficiais de uma API REST.

* Design responsivo com cards estilizados de acordo com os tipos de cada Pokémon (água, fogo, planta, elétrico, etc.).

* Sistema de paginação interativo com o botão "Carregar Mais".
